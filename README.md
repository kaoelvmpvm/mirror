# 鏡面反射光路實驗室

以繁體中文製作的互動式幾何光學教學網頁，適合國中理化課的鏡面反射與球面鏡成像。

## 操作

1. 選擇凸面鏡、凹面鏡或平面鏡，並決定使用物體頂端發光或平行光束。
2. 使用「01 入射 → 02 法線 → 03 反射 → 04 延長 → 05 成像」逐步觀察光路。
3. 初始僅顯示兩條光線；可使用「只觀察一條光線」、左側獨立開關與觀察光線選單降低畫面資訊量。
4. 調整物距、物體高度、曲率半徑、入射點分布與光線數量，也可以拖曳圖中的 O 點。
5. 下載 SVG 或 PNG 作為課堂講義／簡報插圖。

## 重要物理說明

- 實際光線遵守反射定律，入射角與反射角均相對於接觸點法線測量。
- 凸面鏡焦點在鏡後，是虛焦點；鏡前實物不能放在虛焦點上。
- 光路採精確球面幾何反射追跡；焦距、像距與倍率依**近軸鏡公式**計算。遠離光軸的光線會有球面像差，因此幾何光線交點未必與理論像點完全相同。
- 粉紅色虛線是反射光反向延長線，並非光線實際經過的路徑。

## 網站部署

儲存庫由根目錄的 index.html、style.css、app.js 組成，**無需 npm、伺服器或外部依賴**。

若 GitHub Pages 尚未開啟：前往儲存庫 **Settings → Pages → Build and deployment → Deploy from a branch**，選擇 **main** 與 **/(root)**，按下 **Save**。部署完成後網址通常是：

https://kaoelvmpvm.github.io/mirror/

也可以下載三個檔案放在同一資料夾，直接用瀏覽器開啟 index.html。
