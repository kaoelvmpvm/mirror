# 反射與折射光路實驗室

互動式幾何光學教學網頁，提供六種器材，適合國中理化課示範入射、反射、折射、虛像與實像。

## 光學器材

- **凸面鏡**：反射光發散，形成正立縮小虛像。
- **凹面鏡**：依物距形成實像或虛像。
- **平面鏡**：形成正立等大虛像。
- **平面透鏡（此處指平行玻璃板）**：在兩個平行表面折射；斜向入射後，光線出射方向與入射方向平行，但會產生側向位移。玻璃板沒有有限焦點，**不是會聚透鏡**。
- **凸透鏡**：會聚作用；可依物距形成倒立實像或正立虛像。
- **凹透鏡**：發散作用；對鏡前實物形成正立縮小虛像。

## 操作

1. 左側選擇器材，然後選擇「物體頂端」或「平行光束」。
2. 點選「01 入射 → 02 法線 → 03 反射／折射 → 04 延長 → 05 成像」逐步觀察。
3. 初始使用兩條光線，透過單線觀察模式、法線／延長線開關減少圖面重疊。
4. 調整物距、物體高度、曲率半徑、折射率 n、入射點位置與光線數量。
5. 在透鏡的平行光模式下可調整「平行光入射傾角」，其中玻璃板預設為 20°，能直接觀察側向位移。
6. 可拖曳物體頂端，並將圖面匯出 SVG 或 PNG。

## 模型說明與限制

- 鏡面使用反射定律，入射角＝反射角，均以接觸點法線為基準。
- 平行玻璃板、凸透鏡與凹透鏡均計算**兩個介面的折射**，使用司乃耳定律 n₁sinθ₁＝n₂sinθ₂，預設空氣折射率為 1，材料折射率可調。
- 透鏡輪廓使用對稱的球面曲率（平行玻璃板使用平面），示意為具有有限厚度的透鏡；本模型只繪製穿透折射的主光路，**不含**表面部分反射、散射與吸收。
- 透鏡的焦點與像點根據**近軸光線追跡**標示，並不保證所有遠軸光線精確相交（球面像差）；平面玻璃板的虛像位置亦以近軸近似估計。
- 若光線從鏡片邊緣離開或發生全反射，部分光線可能不顯示完整的出射段。
- 反向延長線以虛線表示，是用來推斷虛像位置的作圖工具，不代表光實際走過該路徑。

## 部署與檔案

- `index.html`：網頁介面。
- `style.css`：版面與控制元件。
- `app.js`：共用控制器與鏡面反射。
- `lens.js`：雙介面折射追跡與透鏡成像。

不需要 npm、API 或外部函式庫。

若 GitHub Pages 尚未啟用，至 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**、**main**、**/(root)**、**Save**。
